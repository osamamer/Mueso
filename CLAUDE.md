# Claude instructions

Follow everything in [AGENTS.md](AGENTS.md). In particular:

- After every change, always commit, push (`git push`), and then run `./scripts/install-apk.sh` to build and send the APKs to the phone one by one — no need to ask first.
- Report whether the build succeeded, where the APKs were written, and whether each was installed/sent. If the phone isn't reachable, say so.
